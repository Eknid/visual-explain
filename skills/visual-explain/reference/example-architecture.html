1 Big picture

💡 The 🚦 orchestrator only runs rules and never calls an AI. Every 🤖 LLM, the router included, is a 🐳 container that Scion starts, reads (verdict.json) and stops. GitHub is only the chat: the truth about the PR lives in SQLite 🗄️
